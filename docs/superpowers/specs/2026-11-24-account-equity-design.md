# 账户权益：自动增减与校准

## 意图

现在每笔交易只存开仓时填写的权益，新开仓默认带上一笔的值，不含上一笔盈亏，建议仓位因此基于过期的权益。

本功能保存账户当前权益：平仓后自动增减，开仓时自动带入。与交易所不一致时，用户改一下金额、选一个原因即可校准。差异的常见原因是出金、漏记交易和手续费没记好。

## 目标 / 非目标 / 反目标

**目标**

- 首页显示当前账户权益。
- 平仓、改单、删单后，权益自动反映校准点之后的盈亏。
- 开仓表单默认带入当前权益，仍可手动修改。
- 校准只需填写金额并选择原因。

**非目标**

- 不做权益曲线和出入金报表。
- 不支持编辑或删除校准记录，填错时再校准一次。
- 不补录漏记的交易，漏记只作为校准原因。

**反目标**

- 校准不得改变任何交易的 R 值或策略统计。
- 校准后修改旧单不得重复计入已被校准吸收的差额。

## 方案

- **校准点（已选）**：当前权益 = 最近一次校准余额 + 校准之后平仓交易的盈亏。交易所余额是最终依据，记录只负责两次核对之间的推算。
- **完整流水**：当前权益 = 起始资金 + 全部盈亏 + 全部校正差额。改任何旧单都会影响权益，但先校正后改单会重复计算。
- **单一余额字段**：平仓时直接加减。改单、删单容易算错，也没有校正记录，已排除。

## 设计

**数据**：schema 升到 3，新增表 `equity_calibrations`：

| 字段 | 说明 |
| --- | --- |
| `id` | 自增主键 |
| `balance` | 校准后的实际余额，必须大于 0 |
| `delta` | 保存时的实际余额减推算权益；首次校准为空 |
| `reason` | `cash_flow`（出入金）、`missed_trade`（漏记交易）、`fee`（手续费）、`other`（其他）；首次校准为 `initial` |
| `created_at` | 校准时间 |

**计算**：当前权益 = 最新校准的 `balance` + `closed_at` 晚于该校准 `created_at` 的已平仓交易盈亏之和。盈亏沿用现有公式：方向 ×（出场价 − 入场价）× 数量 − 资金费。持仓中的交易不计入。计算结果不落库，因此改单、删单后自动正确。

**接口**：

- `GET /api/overview` 增加 `equity`（当前权益，未设置时为 null）。`last_equity` 保留，作为未设置时的开仓默认值。
- `POST /api/equity/calibrations` 接收 `balance` 和 `reason`，在同一事务内计算 `delta` 并写入。首次校准忽略传入的原因，存为 `initial`。
- `GET /api/equity/calibrations` 返回校准记录，最新在前。

**界面**：

- 首页显示“账户权益”和“校准”按钮。未设置时显示“设置账户权益”。
- 校准弹窗只有金额和原因两项，金额默认填当前权益，实时显示差额，下方只读列出最近 5 条记录。首次设置不显示原因。
- 有持仓时，弹窗提示填写不含浮动盈亏的钱包余额，否则持仓平仓时盈亏会被重复计入。
- 沿用现有弹窗规则：只能点 × 或“取消”关闭。

**备份**：导出包含校准记录，备份版本升到 3。导入版本 1、2 的备份时没有校准记录，权益回到未设置状态。

**历史数据**：不自动推算起始权益。升级后由用户设置一次当前余额，此前的交易不计入权益。

## 留给实现时决定

- 推算权益小于等于 0 时，开仓表单留空并提示先校准。
- 校准弹窗的具体样式跟随现有组件。
